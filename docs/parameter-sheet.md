# Linux OS基礎インストール演習 パラメータシート

## 1. 基本構成

| 項目 | 設定値 | 設計理由 |
|---|---|---|
| 仮想化ソフト | VirtualBox | 演習指定 |
| OS・バージョン | 未定 | OS決定後に記載 |
| ホスト名 | 未定 | サーバーを識別するため |
| CPU | 1コア | 演習指定 |
| メモリ | 1024MB | 演習指定 |
| ディスク | 20GB・可変サイズ | 演習指定 |
| 想定構成 | Nginx + Tomcat + PostgreSQL | Web/AP/DBを1台に同居 |

## 2. パーティション設計

| マウント先・用途 | サイズ | ファイルシステム | 分離・割り当ての理由 |
|---|---|---|---|
| /boot | 未定 | 未定 | 起動に必要なファイルを配置する |
| / | 未定 | 未定 | OS本体と各種プログラムを配置する |
| /var | 未定 | 未定 | ログなどの増加でルート領域が埋まる影響を抑える |
| swap | 未定 | swap | メモリ不足時の補助領域とする |

※起動方式とOSに応じて、EFIシステムパーティションなどの
追加領域が必要か確認する。
※追加領域も含めてディスク20GB以内に収める。

## 3. 初期設定方針

| 項目 | 設定内容 | 設計理由 |
|---|---|---|
| タイムゾーン | Asia/Tokyo | 日本時間でログを確認するため |
| 作業ユーザー | 未定 | 通常作業用のユーザーを用意するため |
| 不要サービス | OS導入後に一覧を確認して決定 | 使用しない機能の常駐を避けるため |
| 初期導入パッケージ | OS決定後に選定 | 運用・疎通確認に必要なものを導入するため |

※サービスは用途と依存関係を確認してから無効化する。

## 4. ネットワーク設計

| 項目 | 設定値 | 設計理由 |
|---|---|---|
| 接続方式 | ブリッジアダプター | ホストPCと同じLANに接続するため |
| 使用するホスト側アダプター | 未定 | 実際にLANへ接続しているアダプターを使用する |
| IPアドレスの設定方式 | 固定 | 接続先のアドレスを一定にするため |
| VMのIPv4アドレス | 未定 | 重複せず、使用を許可されたアドレスを選定する |
| サブネットマスク・プレフィックス長 | 未定 | 接続先LANの設定に合わせるため |
| デフォルトゲートウェイ | 未定 | 外部ネットワークへ通信するため |
| DNSサーバー | 未定 | ホスト名・ドメイン名を名前解決するため |

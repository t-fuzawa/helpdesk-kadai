# Linux OS基礎インストール演習 パラメータシート

## 1. 基本構成

| 項目 | 設定値 | 設計理由 |
|---|---|---|
| 仮想化ソフト | VirtualBox | 課題指定 |
| OS・バージョン | Ubuntu Server 24.04 LTS | Nginx・Tomcat・PostgreSQLをパッケージ管理の仕組みで導入できる |
| ホスト名 | helpdesk-server | サーバーを識別するため |
| CPU | 1コア | 課題指定 |
| メモリ | 1024MB | 課題指定 |
| ディスク | 20GB・可変サイズ | 課題指定 |
| 想定構成 | Nginx + Tomcat + PostgreSQL | Web/AP/DBを1台に同居 |

## 2. パーティション設計

| マウント先・用途 | サイズ | ファイルシステム | 分離・割り当ての理由 |
|---|---|---|---|
| /boot | 2GB | ext4 | 現在の起動用ファイルだけでなく、更新時に複数の古いカーネルも残す余裕を確保するため |
| / | 残り容量 | ext4 | OS本体や追加ソフトを格納する主要パーティションのため残り全てを割り当てた |
| /var | 5GB | ext4 | ログなど運用中に容量が増えやすいファイルを格納するので多めに確保する。 |
| swap | 2GB | swap | 一時的なメモリ不足に備えてVMに割り当てる実メモリ1GBに対しての2倍の2GBに設定した |

※追加領域も含めてディスク20GB以内に収める。

## 3. 初期設定方針

| 項目 | 設定内容 | 設計理由 |
|---|---|---|
| タイムゾーン | Asia/Tokyo | 日本時間でログを確認するため |
| 作業ユーザー | fuzawa | 通常作業用のユーザーを用意するため |
| 不要サービス | OS導入後に一覧を確認して決定 | 使用しない機能の常駐を避けるため |
| 初期導入パッケージ | openssh-server | 運用・疎通確認に必要なものを導入するため |
| 初期導入パッケージ | iputils-ping | pingを使って他との接続を確認するため |
| 初期導入パッケージ | curl | HTTPやHTTPSの確認を行うため |
| 初期導入パッケージ | dnsutils | digを使ってDNSの名前解決をするため |

※サービスは用途と依存関係を確認してから無効化する。

## 4. ネットワーク設計

| 項目 | 設定値 | 設計理由 |
|---|---|---|
| 接続方式 | NAT | VirtualBoxのNAT機能を経由して外部ネットワークへ通信するため |
| IPアドレス設定 | DHCPによる自動取得 | VirtualBoxのNAT機能からネットワーク設定を自動取得するため |
| SSHポートフォワーディング | TCP / 127.0.0.1:2222 → ゲスト:22 | ホストPCからUbuntuへSSH接続するため |
| HTTPポートフォワーディング | TCP / 127.0.0.1:8080 → ゲスト:80 | ホストPCのブラウザからNginxへHTTP接続するため |
| SSH接続方法 | `ssh -p 2222 fuzawa@127.0.0.1` | ホストPCの2222番ポートを経由してVMの22番ポートへ接続するため |
| HTTP接続方法 | `http://127.0.0.1:8080` | ホストPCの8080番ポートを経由してVMの80番ポートへ接続するため |
